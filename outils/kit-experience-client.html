⚙️ Procédure — comment envoyer ce mail depuis Brevo
✅ Option recommandée — Template Brevo + envoi manuel en 2 clics

Ce mail reste manuel — il doit être envoyé dans l'heure qui suit la séance, avec votre intention. Pas d'automatisation ici. La procédure prend 90 secondes une fois le template créé.

1
Créer le template dans Brevo — une seule fois
Brevo → menu latéral Campagnes → Modèles → Créer un modèle. Nommez-le "Mail 3 — Clôture post-séance". Collez le texte ci-dessous dans l'éditeur. Laissez [Prénom] tel quel — vous le remplacerez à l'envoi.
2
Après chaque séance — ouvrir Brevo sur mobile ou ordinateur
Brevo → Contacts → cherchez la cliente par son prénom ou email → cliquez sur son profil → bouton "Envoyer un email" (ou "Send email" si l'interface est en anglais).
3
Sélectionner le template et personnaliser
Dans la fenêtre d'envoi → Choisir un modèle → sélectionnez "Mail 3 — Clôture post-séance". Remplacez [Prénom] par son prénom réel. Vérifiez l'objet. Cliquez Envoyer. C'est fait.
💡
Astuce — créez un raccourci sur l'écran d'accueil de votre téléphone
Brevo a une appli mobile. Ajoutez l'icône sur votre écran d'accueil. Juste après avoir raccroché, vous ouvrez l'app, vous sélectionnez le template, vous envoyez en 60 secondes. Ce geste immédiat devient un rituel de clôture pour vous aussi.

💡 Conseils techniques pour une image impeccable

Lumière : toujours face à vous (fenêtre ou lampe devant, jamais derrière). Une lumière de dos = silhouette sur fond clair. Investissez dans une lampe annulaire LED (15-25€ sur Amazon) si la lumière naturelle est insuffisante.

Caméra : à hauteur des yeux, jamais en contre-plongée. Posez votre ordinateur sur des livres si nécessaire. Cadrez entre le haut de la tête et le milieu de la poitrine — ni trop près ni trop loin.

Fond physique idéal : si vous préférez un fond réel à l'image virtuelle — un mur uni blanc cassé ou grège, avec une plante verte sur le côté et un ou deux objets soignés (carafe en verre, carnet cuir). Moins il y a d'éléments, plus c'est professionnel.

🎥 Fond virtuel KMeet — procédure d'installation
📌 Comment installer le fond dans KMeet (Infomaniak)

Pendant une réunion KMeet : cliquez sur les 3 points … en bas de l'écran → "Changer d'arrière-plan" → "Arrière-plans virtuels" → bouton "+" ou "Ajouter une image" → sélectionnez le fichier PNG exporté depuis l'onglet "Fond virtuel" de ce kit (imprimez → Enregistrer en PDF → convertissez en PNG via un outil gratuit comme smallpdf.com).

Conseil : testez le fond avant votre première vraie séance. Certains environnements ont besoin d'un fond uni physique derrière vous pour que KMeet détecte bien la silhouette. Un mur blanc cassé ou grège fonctionne parfaitement.
