Bonjour,

Il y a quelque chose qu'on ne vous dit jamais quand on vous diagnostique un SIBO — ou un intestin irritable, ou une simple "hypersensibilité" — c'est que votre thyroïde est peut-être en cause.

Voici pourquoi.

La thyroïde et le CMM

Entre les repas, votre intestin grêle se nettoie grâce à des contractions péristaltiques appelées Complexe Moteur Migrant (CMM). Ce mécanisme fonctionne toutes les 90 minutes à jeun — c'est lui qui évite la prolifération bactérienne.

Or, les hormones thyroïdiennes régulent directement la motilité intestinale. Une hypothyroïdie — même légère, même dans les « normes » biologiques — ralentit ce CMM. Les bactéries s'accumulent. Le SIBO s'installe ou récidive.

C'est pour ça que traiter un SIBO sans vérifier la thyroïde, c'est souvent perdre du temps — et comprendre pourquoi on rechute.

Ce que je recommande à mes clientes :

Bilan thyroïdien fonctionnel
→
Faire doser TSH + T4 libre + T3 libre (pas seulement la TSH)
→
Vérifier aussi le sélénium, le zinc et l'iode — souvent déficients dans le SIBO, et nécessaires à la synthèse des hormones thyroïdiennes
→
Demander une interprétation fonctionnelle, pas seulement « dans la norme »

Cette connexion thyroïde ↔ SIBO est détaillée dans le guide complet, avec les autres liens hormonaux : SOPK, endométriose, SPM sévère, périménopause.

Guide de configuration

Mettre en place la séquence dans Brevo

Voici la procédure exacte pour configurer cette séquence automatique dans Brevo — de la création des templates à l'activation de l'automation.

Étape 1 — Créer les 4 templates email

1
Dans Brevo → Campagnes → Templates → Créer un template. Nommez-le SIBO_sequence_J0. Collez le corps HTML du Mail 1 (bouton "Copier le corps HTML" ci-dessus). Objet : Votre guide SIBO est là. 🌿
2
Répétez pour les 3 autres mails : SIBO_sequence_J14, SIBO_sequence_J28, SIBO_sequence_J42. Notez l'ID numérique de chaque template (affiché dans l'URL).
3
Pour le Mail 1 : dans le template, section Pièces jointes, ajoutez ebook_sibo_light_avitaserena.pdf. Ou hébergez le PDF sur votre site et remplacez le texte "en pièce jointe" par un lien de téléchargement.

Étape 2 — Créer l'automation

1
Dans Brevo → Automations → Créer une automation → Démarrer de zéro.
2
Déclencheur : "Un contact est ajouté à une liste" → sélectionnez la liste Leads SIBO. Ou "Un contact reçoit un attribut" → EBOOK_TELECHARGE = sibo-light.
3
Enchaînement : Envoyer Mail 1 (J+0) → Attendre 14 jours → Envoyer Mail 2 → Attendre 14 jours → Envoyer Mail 3 → Attendre 14 jours → Envoyer Mail 4.
4
Ajoutez une condition de sortie : "Si le contact se désabonne → fin de séquence". Brevo le fait automatiquement mais vérifiez que c'est activé.
5
Nommez l'automation Séquence ebook SIBO, activez-la. Testez avec votre propre adresse email avant de la lancer.

Étape 3 — Connecter le formulaire du site

1
Dans ebook-sibo.html, la fonction handleLight() est prête. Remplacez-la par un appel à l'API Brevo qui ajoute le contact à la liste Leads SIBO avec l'attribut EBOOK_TELECHARGE = sibo-light. L'automation se déclenche automatiquement.
2
Clé API à utiliser : votre clé Brevo (déjà configurée dans l'agenda). Endpoint : POST https://api.brevo.com/v3/contacts.
