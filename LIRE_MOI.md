# Avita Serena — Instructions

## Changer le mot de passe chaque mois

1. Ouvre le fichier  →  outils/index.html
2. Cherche la ligne (ligne ~180) :
   const MOT_DE_PASSE = "kalliste";
3. Remplace kalliste par ton nouveau mot de passe
4. Sauvegarde le fichier
5. Redéploie sur Netlify (glisser-déposer le dossier)
